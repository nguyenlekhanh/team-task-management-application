### Page-content headers — VERIFIED ADEQUATE, LEFT UNTOUCHED
All 10 standard headers share the same `text-2xl font-bold text-gray-900` +

GroupDetail, TaskDetail, TaskList, centered Login/Register). Spacing, hierarchy, and
readability are consistent. No changes made — documented decision.

### REAL ISSUES FOUND → FIXED (7 fixes)
1. **Full-page error-state buttons drifted from the standard**: TaskDetail "Go Back"
   and GroupDetail "Back to Groups" were plain `px-4 py-2` (36px, no ring) while the
   identical TaskList "Retry" button (same pattern, same layout) has `min-h-[44px]`.
   → Both now min-h-[44px] + focus-visible ring; existing handlers preserved
   (history.back / navigate to groups).
2. **TaskCreatePage / TaskEditPage in-card back buttons**: no min-h, no ring.
   → min-h-[44px] + focus-visible ring (+ inline-flex alignment on TaskCreate's).
3. **Long titles could break TaskDetail/GroupDetail content-header layout**: task
   titles allow 200 chars; `text-2xl` beside badges wrapped messily on mobile.
   → `break-words` on both titles (clean wrapping; no truncation — titles stay
   fully readable).
4. **Groups table empty state was a bare text line** ("No groups yet. Create your
   first group!") — no icon, no CTA, inconsistent with the TaskList/MyTasks gold
   standard, and the "create your first group!" instruction offered no button.
   → Gold-standard empty state: decorative SVG (aria-hidden) + "No groups yet" h3 +
   message + **Create Group CTA wired to the existing `setShowCreateModal(true)`**
   (zero new logic).
5. **MyTasks empty-state CTAs below the 8.x standard**: "Clear filters" and
   "Go to Groups" lacked the min-h-[44px] + ring that TaskList's equivalent buttons
   already have. → Both fixed to match.
6. **MyTasks empty-state SVG missing `aria-hidden="true"`** (TaskList's has it) —
   decorative icon was exposed to assistive tech. → Added.
7. **GroupDetail members table had NO empty state**: a zero-member group (defensive
   case; impossible via normal flows since an owner always exists) rendered headers
   with an empty tbody. → Defensive "No members yet." row (colSpan=4), matching the
   Groups/TaskList/MyTasks empty-row convention.

### Verified adequate, left untouched (documented)
- Dashboard's three in-card empty texts ("No recent tasks." / "No notifications." /
  "You are not a member of any group yet.") — minimal by design inside populated
  cards, clear and useful; gold-standard treatment would add noise, not value
- Checklist ("No checklist items yet" + Add First Item CTA), ChatPanel ("Be the
  first to send one!"), CommentSection, NotificationDropdown ("No notifications yet")
  — component-level empty states already clear and actionable
- Error-page header wording/structure (h2 + message) on all error screens
- All 8.1–8.3 work re-verified present: shared Navbar + hamburger, all 6 tables
  inside overflow-x-auto, stacked page headers/pagination, modal action-row stacking,
  44px auth controls, Delete Task wiring — no regressions
