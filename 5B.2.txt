## IMPLEMENTATION

### Files Created

**Backend Migration (New):**
- `backend/migrations/20240821190006-create-messages.js` - Creates Messages table with:
  - id (PK, auto-increment)
  - senderId (FK → Users.id, NOT NULL, CASCADE)
  - groupId (FK → Groups.id, NULLABLE, CASCADE) - for group chat
  - taskId (FK → Tasks.id, NULLABLE, CASCADE) - for task comments
  - content (TEXT, NOT NULL, max 5000 chars)
  - messageType (ENUM: 'message', 'comment', 'system', DEFAULT 'message')
  - createdAt, updatedAt (DATE, DEFAULT NOW)
  - Indexes: groupId, taskId, (groupId, createdAt), (taskId, createdAt), senderId
  - FK: senderId → Users (CASCADE), groupId → Groups (CASCADE), taskId → Tasks (CASCADE)

**Backend Model (New):**
- `backend/src/models/Message.js` - Message Sequelize model with all fields, indexes, and associations:
  - Message.belongsTo(User, { as: 'sender', foreignKey: 'senderId', onDelete: 'CASCADE' })
  - Message.belongsTo(Group, { as: 'group', foreignKey: 'groupId', onDelete: 'CASCADE' })
  - Message.belongsTo(Task, { as: 'task', foreignKey: 'taskId', onDelete: 'CASCADE' })

### Files Modified

**Backend Models (Modified):**
- `backend/src/models/User.js` - Added: `User.hasMany(Message, { as: 'sentMessages', foreignKey: 'senderId' })`
- `backend/src/models/Group.js` - Added: `Group.hasMany(Message, { as: 'messages', foreignKey: 'groupId', onDelete: 'CASCADE' })`
- `backend/src/models/Task.js` - Added: `Task.hasMany(Message, { as: 'comments', foreignKey: 'taskId', onDelete: 'CASCADE' })`
- `backend/src/models/index.js` - Auto-loads Message model (no changes needed)

### Database Changes
- New table: `Messages` with 10 columns, 5 indexes, 3 foreign keys
- Migration recorded in SequelizeMeta: `20240821190006-create-messages.js`
