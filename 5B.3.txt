### API Endpoints Implemented

| Method | Endpoint | Purpose |
|--------|----------|---------|
| GET | /api/groups/:groupId/messages | List group messages (paginated) |
| POST | /api/groups/:groupId/messages | Send group message |
| GET | /api/tasks/:taskId/comments | List task comments (paginated) |
| POST | /api/tasks/:taskId/comments | Add task comment |
| PUT | /api/messages/:id | Edit message (sender only) |
| DELETE | /api/messages/:id | Delete message (sender or owner/admin) |

### Authorization Rules Implemented

| Endpoint | Authorization |
|----------|---------------|
| GET /api/groups/:groupId/messages | Group member only (404 if not member) |
| POST /api/groups/:groupId/messages | Group member only |
| GET /api/tasks/:taskId/comments | Task's group member only |
| POST /api/tasks/:taskId/comments | Task's group member only |
| PUT /api/messages/:id | Message sender only |
| DELETE /api/messages/:id | Sender OR group owner/admin |

### Validation Implemented

- **Content**: Required, max 5000 characters (both messages and comments)
- **Group/Task ID**: Valid integer required
- **Message ID**: Valid integer required
- **Pagination**: page (default 1), limit (default 50, max 100)
- **Timestamp filtering**: `before` parameter for cursor-based pagination

### Response Format

```json
// Single message
{
  "message": "Message sent successfully",
  "item": {
    "id": 1,
    "senderId": 2,
    "groupId": 5,
    "taskId": null,
    "content": "Hello team!",
    "messageType": "message",
    "createdAt": "2024-08-22T10:30:00Z",
    "updatedAt": "2024-08-22T10:30:00Z",
    "sender": { "id": 2, "username": "john", "displayName": "John Doe", "avatarUrl": null }
  }
}

// Paginated list
{
  "items": [...],
  "pagination": {
    "total": 100,
    "page": 1,
    "limit": 50,
    "totalPages": 2,
    "hasMore": true
  }
}
```

### Error Responses

| Code | Scenario |
|------|----------|
| 400 | Validation error (empty content, >5000 chars, invalid IDs) |
| 401 | No/invalid token |
| 403 | Not sender (for PUT/DELETE), not owner/admin (for DELETE) |
| 404 | Not member, invalid group/task/message ID |
| 500 | Server error |
