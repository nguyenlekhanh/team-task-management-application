## KNOWN ISSUES

1. **Server Process Management**: Background server processes terminate when shell exits (infrastructure limitation, not code issue). Using `nohup` keeps server stable for testing.

2. **JWT Token Expiry**: Tokens expire after 15 minutes (expected behavior). Tests require fresh tokens.

3. **Owner/Admin Delete Test**: Fully tested with testuser (owner) - can delete any message.

4. **Non-sender/Non-admin Delete**: Logic implemented but not tested with separate admin user. Code path exists.

5. **Server Stability**: Server runs stably with `nohup` but dies after requests when run in background with `&`. Production deployment should use proper process manager (PM2, systemd).

5. **No Real-time Updates**: Uses polling/pagination only (Socket.IO planned for Phase 5D).

6. **No Message Editing UI**: Uses browser prompt for editing (can be enhanced with modal in future).

7. **No Unread Indicators**: Not implemented yet.

8. **No File/Image Attachments**: Text only for MVP.

## BUGS FIXED DURING TESTING

1. **Server Stability**: Fixed by running with `nohup` instead of background `&` - prevents server from dying after requests when shell exits.

2. **Token Handling**: Fixed token variable substitution in test scripts.
