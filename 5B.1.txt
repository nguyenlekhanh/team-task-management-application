## FUNCTIONAL REQUIREMENTS

### Core Features
1. **Group Chat**: Real-time messaging within groups
2. **Task Comments**: Threaded comments on tasks
3. **Message Types**: Text messages, system messages (task created, user joined, etc.)
4. **Pagination**: Load older messages on scroll
5. **Authorization**: Only group members can read/write messages

### User Stories
- As a **group member**, I want to send messages to my group
- As a **task assignee**, I want to comment on tasks
- As a **group member**, I want to see message history with pagination
- As a **group owner**, I want to moderate messages if needed

## DATABASE DESIGN

### Messages Table (New)
| Field | Type | Constraints | Description |
|-------|------|-------------|-------------|
| id | INTEGER | PK, auto-increment | Unique identifier |
| senderId | INTEGER | FK → Users.id, NOT NULL, CASCADE | Message author |
| groupId | INTEGER | FK → Groups.id, NULLABLE, CASCADE | Group (for group chat) |
| taskId | INTEGER | FK → Tasks.id, NULLABLE, CASCADE | Task (for task comments) |
| content | TEXT | NOT NULL | Message content |
| messageType | ENUM | DEFAULT 'message' | 'message', 'comment', 'system' |
| createdAt | DATE | DEFAULT NOW | Creation timestamp |
| updatedAt | DATE | DEFAULT NOW | Last update timestamp |

### Constraints
- Either `groupId` OR `taskId` must be set (not both, not neither)
- FK: senderId → Users.id (CASCADE on delete)
- FK: groupId → Groups.id (CASCADE on delete)
- FK: taskId → Tasks.id (CASCADE on delete)

### Indexes
- `groupId` - for group chat queries
- `taskId` - for task comment queries
- `(groupId, createdAt)` - for paginated group messages
- `(taskId, createdAt)` - for paginated task comments

### Model Associations
- User.hasMany(Message, { as: 'sentMessages', foreignKey: 'senderId' })
- Message.belongsTo(User, { as: 'sender', foreignKey: 'senderId', onDelete: 'CASCADE' })
- Group.hasMany(Message, { as: 'messages', foreignKey: 'groupId', onDelete: 'CASCADE' })
- Message.belongsTo(Group, { as: 'group', foreignKey: 'groupId', onDelete: 'CASCADE' })
- Task.hasMany(Message, { as: 'comments', foreignKey: 'taskId', onDelete: 'CASCADE' })
- Message.belongsTo(Task, { as: 'task', foreignKey: 'taskId', onDelete: 'CASCADE' })

## API DESIGN

### Endpoints

#### 1. GET /api/groups/:groupId/messages
**Purpose**: List group messages (paginated)
- **Auth**: Required
- **Authorization**: Group member
- **Query Params**: 
  - `page` (default: 1)
  - `limit` (default: 50, max: 100)
  - `before` (timestamp, for pagination - messages before this time)
- **Response**: 
```json
{
  "items": [
    {
      "id": 1,
      "senderId": 2,
      "groupId": 5,
      "taskId": null,
      "content": "Hello team!",
      "messageType": "message",
      "createdAt": "2024-08-22T10:30:00Z",
      "updatedAt": "2024-08-22T10:30:00Z",
      "sender": { "id": 2, "username": "john", "displayName": "John Doe", "avatarUrl": null }
    }
  ],
  "pagination": { "page": 1, "limit": 50, "hasMore": true }
}
```
- **Errors**: 401, 404 (group not found/access denied)

#### 2. POST /api/groups/:groupId/messages
**Purpose**: Send a message to group chat
- **Auth**: Required
- **Authorization**: Group member
- **Body**: `{ "content": "Hello team!" }`
- **Validation**: content required, max 5000 chars
- **Response**: 201 Created with message (including sender object)
- **Errors**: 400 (validation), 401, 404

#### 3. GET /api/tasks/:taskId/comments
**Purpose**: List task comments (paginated)
- **Auth**: Required
- **Authorization**: Task's group member
- **Query Params**: page, limit, before
- **Response**: Same format as group messages
- **Errors**: 401, 404 (task not found/access denied)

#### 4. POST /api/tasks/:taskId/comments
**Purpose**: Add a comment to a task
- **Auth**: Required
- **Authorization**: Task's group member
- **Body**: `{ "content": "This task needs review" }`
- **Validation**: content required, max 5000 chars
- **Response**: 201 Created with comment (including sender)
- **Errors**: 400, 401, 404

#### 5. PUT /api/messages/:id
**Purpose**: Edit a message/comment (sender only)
- **Auth**: Required
- **Authorization**: Message sender
- **Body**: `{ "content": "Updated message" }`
- **Validation**: content required, max 5000 chars
- **Response**: 200 with updated message
- **Errors**: 400, 401, 403 (not sender), 404

#### 6. DELETE /api/messages/:id
**Purpose**: Delete a message/comment (sender or group owner/admin)
- **Auth**: Required
- **Authorization**: Sender, or group owner/admin
- **Response**: 200 { "message": "Message deleted" }
- **Errors**: 401, 403, 404

## RISKS / EDGE CASES

| Risk | Mitigation |
|------|------------|
| Task deletion | CASCADE deletes task comments automatically |
| Group deletion | CASCADE deletes group messages |
| User deletion | CASCADE deletes sent messages (or SET NULL if preferred) |
| Large message history | Pagination with cursor-based (before timestamp) |
| Concurrent edits | Last-write-wins acceptable for MVP |
| Long messages | Max 5000 chars validation |
| Non-member access | Return 404 (not 403) to avoid info leakage |
| Deleted messages | Soft delete? For MVP: hard delete |
